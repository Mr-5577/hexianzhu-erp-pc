# ERP 管理系统

基于 Vue 3 + TypeScript + Vite 构建的现代化 ERP 管理系统。

## 技术栈

- **核心框架**: Vue 3.5.40 (Composition API)
- **构建工具**: Vite 8.1.5
- **编程语言**: TypeScript 6.0.0
- **状态管理**: Pinia 4.0.2
- **路由管理**: Vue Router 5.2.0
- **代码格式化**: oxfmt
- **包管理**: npm (Node.js 22.18.0+)

## 环境要求

- Node.js: ^22.18.0 或 >=24.12.0
- npm: 最新版本

## 快速开始

### 安装依赖

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```
